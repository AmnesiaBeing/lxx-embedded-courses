请协助完成 Rust 嵌入式开发环境的搭建：

# 背景信息

1. 目标开发芯片：STM32F103ZET6
2. 目标调试工具：J-Link
3. 当前开发环境：TRAE
4. 希望使用 probe-rs 进行调试

# 限制条件

1. TRAE 编辑器仅能读取当前工作目录下的文件，读写外部文件必须通过命令行执行
2. 必须适配国内网络环境，优先使用阿里云 Rust 镜像源
3. 每一步安装执行前，请先验证当前环境是否存在相关工具或配置，避免重复安装或冲突
4. 执行前先判断当前的运行环境，如果识别到是 Linux，还可能需要判断一下是否是 WSL2 环境，因为 WSL2 环境下需要额外配置一些东西

# 任务目标

## 1. 安装并配置 rustup

- 配置 rustup 阿里云镜像环境变量（临时+永久生效）
- 安装 rustup 并配置 ARM Cortex-M3 交叉编译工具链（target: thumbv7m-none-eabi）
- 验证 rustup 安装结果，确保 rustc、cargo、rustup 命令可正常执行

## 2. 配置 cargo 镜像源

- 编辑`~/.cargo/config.toml`文件，写入阿里云 crates.io 镜像配置
- 验证 cargo 源配置，确保后续依赖下载走阿里云镜像

## 3. 完整配置 probe-rs

- 安装参考链接：https://probe.rs/docs/getting-started/installation/
- 配置参考链接：https://probe.rs/docs/getting-started/probe-setup/
- 通过 cargo 安装 probe-rs：`cargo install probe-rs-tools --locked`
- 配置 udev 规则（适配 J-Link 设备），确保普通用户无需 sudo 即可访问 J-Link
  - 注意配置规则文件需要从 probe-rs 配置参考文档中获取，以适配各种 probe-rs 支持的适配器
- （如果是 WSL）配置 WSL2 的 udev 服务自启动（编辑`/etc/wsl.conf`）
