请协助完成Rust嵌入式开发环境的搭建：

# 背景信息
1. 目标开发芯片：STM32F103ZET6
2. 目标调试工具：J-Link
3. 当前开发环境：TRAE
4. 希望使用probe-rs进行调试

# 限制条件
1. TRAE编辑器仅能读取当前工作目录下的文件，读写外部文件必须通过命令行执行
2. 必须适配国内网络环境，优先使用阿里云Rust镜像源
3. 每一步安装执行前，请先验证当前环境是否存在相关工具或配置，避免重复安装或冲突
4. 执行前先判断当前的运行环境，如果识别到是Linux，还可能需要判断一下是否是WSL2环境，因为WSL2环境下需要额外配置一些东西

# 任务目标
## 1. 安装并配置rustup
- 配置rustup阿里云镜像环境变量（临时+永久生效）
- 安装rustup并配置ARM Cortex-M3交叉编译工具链（target: thumbv7m-none-eabi）
- 验证rustup安装结果，确保rustc、cargo、rustup命令可正常执行

## 2. 配置cargo镜像源
- 编辑`~/.cargo/config.toml`文件，写入阿里云crates.io镜像配置
- 验证cargo源配置，确保后续依赖下载走阿里云镜像

## 3. 完整配置probe-rs
- 安装参考链接：https://probe.rs/docs/getting-started/installation/
- 配置参考链接：https://probe.rs/docs/getting-started/probe-setup/
- 通过cargo安装probe-rs：`cargo install probe-rs-tools --locked`
- 配置udev规则（适配J-Link设备），确保普通用户无需sudo即可访问J-Link
  - 注意配置规则文件需要从probe-rs配置参考文档中获取，以适配各种probe-rs支持的适配器
- （如果是WSL）配置WSL2的udev服务自启动（编辑`/etc/wsl.conf`）
