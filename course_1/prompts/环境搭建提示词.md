请基于以下背景完成WSL2环境下STM32F103ZET6的Rust+probe-rs开发环境配置：

# 背景信息
1. 操作系统：Windows 11 + WSL2（Ubuntu 22.04）
2. 已完成Windows侧准备：
   - 安装TRAE编辑器（已安装rust-analyzer、probe-rs-debugger插件）
   - 安装J-Link官方驱动、usbipd-win工具
   - 完成WSL2安装并升级至最新版本
3. 目标芯片：STM32F103ZET6（ARM Cortex-M3架构，需适配thumbv7m-none-eabi编译目标）

# 限制条件
1. TRAE编辑器仅能读取当前工作目录下的文件，系统级配置（如安装工具、修改系统服务）必须通过命令行执行；
2. 必须适配国内网络环境，优先使用阿里云Rust镜像源
3. 每一步安装执行前，请先验证当前环境是否存在相关工具或配置，避免重复安装或冲突
4. 允许执行sudo命令，但是要告知用户需要对命令行窗口进行操作

# 任务目标
## 1. 安装并配置rustup
- 配置rustup阿里云镜像环境变量（临时+永久生效），执行以下核心指令并确保生效：
  ```bash
  export RUSTUP_UPDATE_ROOT=https://mirrors.aliyun.com/rustup/rustup
  export RUSTUP_DIST_SERVER=https://mirrors.aliyun.com/rustup
  ```
- 安装rustup并配置ARM Cortex-M3交叉编译工具链（target: thumbv7m-none-eabi）
- 验证rustup安装结果，确保rustc、cargo、rustup命令可正常执行

## 2. 配置cargo镜像源
- 编辑`~/.cargo/config.toml`文件，写入阿里云crates.io镜像配置，内容如下（需确保文件存在且配置生效）：
  ```toml
  [source.crates-io]
  replace-with = 'aliyun'
  [source.aliyun]
  registry = "sparse+https://mirrors.aliyun.com/crates.io-index/"
  ```
- 验证cargo源配置，确保后续依赖下载走阿里云镜像

## 3. 完整配置probe-rs（含USB桥接、udev权限、J-Link适配）
- 安装参考链接：https://probe.rs/docs/getting-started/installation/
- 配置参考链接：https://probe.rs/docs/getting-started/probe-setup/
- 通过cargo安装probe-rs：`cargo install probe-rs-tools --locked`
- 配置probe-rs命令行补全功能：`probe-rs complete install`
- 配置udev规则（适配J-Link设备），确保普通用户无需sudo即可访问J-Link
  - 注意配置规则文件需要从probe-rs配置参考文档中获取，以适配各种probe-rs支持的适配器
- 配置WSL2的udev服务自启动（编辑`/etc/wsl.conf`）

## 4. 创建嵌入式项目
- 使用`cargo init .`创建名为`course_1`的项目（项目目录为当前工作目录）
- 通过`cargo add`命令，添加STM32F103ZET6所需依赖：
  - 只需添加这些依赖：cortex-m、cortex-m-rt、stm32f1xx-hal、rtt-target、panic-rtt-handler
  - 其中，stm32f1xx-hal库需要添加`stm32f103`特征
  - cortex-m-rt库已提供了memory.x链接脚本，无需额外添加其他文件
- `src/main.rs`的目标功能说明：
  - 确保正确使用panic-hanlder
  - 在`src/main.rs`中正确初始化rtt-target，并且通过rtt-target打印"Hello World!\n"，然后执行空循环

## 5. 配置快捷运行和调试功能
- 请添加`.cargo/config.toml`文件，配置默认编译目标为thumbv7m-none-eabi，并且修改默认执行工具为probe-rs
- 请添加`.vscode/tasks.json`文件，用于编译当前项目，默认以Debug模式编译
- 请添加`.vscode/settings.json`文件，告知rust-analyzer只针对thumbv7m-none-eabi目标进行检查，禁用其他平台的代码分析，以避免不必要的编辑器警告
- probe-rs-debugger参考链接：https://probe.rs/docs/tools/debugger/
- 请按参考链接配置`.vscode/launch.json`，要求支持RTT-TARGET，默认日志等级为debug，并在调试任务运行前先执行编译功能

## 6. 调试指引
- 最后请编写README.md文件，告知用户如何进行下一步调试
- 参考链接：https://learn.microsoft.com/zh-cn/windows/wsl/connect-usb
- 告知用户需要通过usbipd-win将物理机的J-Link USB设备桥接至WSL2
  - 注意，在WSL环境中执行Windows下的命令，需要使用`usbipd.exe`而不是`usbipd`
- 验证WSL2中可通过lsusb命令识别J-Link设备
- 最后告知用户已配置好，可以使用F5快捷键开始调试
