请协助完成 Rust 嵌入式项目的搭建：

# 背景信息

1. 目标开发芯片：STM32F103ZET6
2. 目标调试工具：J-Link
3. 当前开发环境：TRAE（一种基于VSCODE的AI编辑器）
4. 希望使用 probe-rs 进行调试

# 任务目标

## 1. 创建嵌入式项目

- 使用`cargo init .`在当前目录下创建新的 Rust 项目

## 2. 添加所需依赖

- 通过`cargo add`命令，添加 STM32F103ZET6 所需依赖：
  - 只需添加这些依赖：
    - `cortex-m`
      - 需要添加`critical-section-single-core`特征
    - `cortex-m-rt`
    - `stm32f1xx-hal`
      - 需要添加`stm32f103`特征
    - `rtt-target`
    - `panic-rtt-target`

## 3. 编写 Hello World!

- `src/main.rs`的目标功能说明：
  - 确保正确使用 panic-hanlder
  - 在`src/main.rs`中正确初始化 rtt-target，并且通过 rtt-target 打印"Hello World!\n"，然后执行`nop`指令的循环，不允许进入休眠状态
  - 每一行都需要增加注释
- 针对 STM32F103ZET6，编写正确的`memory.x`链接脚本文件

## 4. 配置默认编译目标并尝试编译

- 配置`.cargo/config.toml`文件，添加默认编译目标为 thumbv7m-none-eabi
- 尝试编译项目，确保无错误

## 5. 配置快捷运行和调试功能

- rust-analyzer 插件配置参考链接：https://rust-analyzer.github.io/book/editor_features.html#vs-code
- 请添加`.vscode/settings.json`文件，告知 rust-analyzer 只针对 thumbv7m-none-eabi 目标进行检查，禁用其他平台的代码分析，以避免不必要的编辑器警告
- probe-rs-debugger 插件配置参考链接：https://probe.rs/docs/tools/debugger/
- 请添加`.vscode/tasks.json`文件，用于编译当前项目，默认以 Debug 模式编译
- 请添加`.vscode/launch.json`文件，要求支持 rtt-target 输出功能

## 6. 调试指引

- 最后请编写 README.md 文件，告知用户如何进行下一步调试
- 参考链接：https://learn.microsoft.com/zh-cn/windows/wsl/connect-usb
- （如果是 WSL）告知用户需要通过 usbipd-win 将物理机的 J-Link USB 设备桥接至 WSL2
  - 注意，在 WSL 环境中执行 Windows 下的命令，需要使用`usbipd.exe`而不是`usbipd`
- （如果是 WSL）验证 WSL2 中可通过 lsusb 命令识别 J-Link 设备
- 最后告知用户已配置好，可以使用 F5 快捷键开始调试
